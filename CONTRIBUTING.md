# Contributing / Katkı

Open a small issue describing the user problem without private server data. For a change, use Node.js 24.13+, `npm ci --ignore-scripts`, `npm run check` and `npm audit --audit-level=low`. Run helper syntax checks with `bash -n setup.sh start.sh`. Keep `npm` lock entries, strict types, permission rechecks, mention suppression and bounded memory. Test state transitions and failure behavior, not only happy paths. Use a separate Discord development application and private test server for manual tests; never commit its token. State which checks you actually ran. All contributions use the MIT license.

Özel sunucu verisi eklemeden kullanıcı sorununu açıklayan küçük bir issue açın. Değişiklikler için Node.js 24.13+, `npm ci --ignore-scripts`, `npm run check` ve `npm audit --audit-level=low` kullanın. Yardımcı sözdizimini `bash -n setup.sh start.sh` ile denetleyin. Kilit dosyasını, katı tipleri, yetki denetimlerini, etiket bastırmayı ve sınırlı belleği koruyun. Durum geçişlerini ve hata davranışlarını test edin. Elle test için ayrı bir Discord geliştirme uygulaması ve özel test sunucusu kullanın; tokenı asla commit etmeyin. Gerçekten çalıştırdığınız kontrolleri belirtin. Katkılar MIT lisansı kapsamındadır.
